## How to Contribute | كيفية المساهمة

### 1. Reporting Bugs or Issues | الإبلاغ عن الأخطاء أو المشكلات
- Check the [existing issues](https://github.com/slam-prog/KineticVoice/issues) to avoid duplicates.
- If your issue is new, open a new issue with a clear title and description.
- Include steps to reproduce, expected behavior, and any relevant logs or screenshots.

- تحقق من [المشكلات الحالية](https://github.com/slam-prog/KineticVoice/issues) لتجنب التكرار.
- إذا كانت مشكلتك جديدة، افتح مشكلة جديدة بعنوان ووصف واضحين.
- أرفق خطوات إعادة الإنتاج، والسلوك المتوقع، وأي سجلات أو لقطات شاشة ذات صلة.

### 2. Suggesting Enhancements | اقتراح التحسينات
- Open a new issue with the **"enhancement"** label.
- Describe your idea clearly, why it would be valuable, and any potential implementation approaches.

- افتح مشكلة جديدة بوسم **"enhancement"** (تحسين).
- صف فكرتك بوضوح، ولماذا ستكون ذات قيمة، وأي نهج تنفيذية محتملة.

### 3. Pull Request Process | عملية طلبات السحب
1. Fork the repository and create a new branch for your feature or bugfix.
2. Ensure your code follows the project's coding style (consistent indentation, clear comments, etc.).
3. Write clear, descriptive commit messages.
4. Test your changes thoroughly on your local hardware setup if possible.
5. Open a Pull Request (PR) with a detailed description of your changes.
6. Wait for reviews from the project maintainers.

1. انسخ (Fork) المستودع وأنشئ فرعاً جديداً لميزتك أو إصلاحك.
2. تأكد من أن كودك يتبع نمط الترميز الخاص بالمشروع (مسافات بادئة متسقة، تعليقات واضحة، إلخ).
3. اكتب رسائل التزام (Commit) واضحة ووصفية.
4. اختبر تغييراتك بدقة على إعدادات العتاد المحلية إن أمكن.
5. افتح طلب سحب (Pull Request) مع وصف تفصيلي لتغييراتك.
6. انتظر المراجعات من مسؤولي المشروع.

### 4. Improving Documentation | تحسين التوثيق
- Documentation is crucial for this project. You can improve the `README.md`, add new guides, or enhance existing files.
- Open a PR with your documentation changes.

- التوثيق أمر حاسم لهذا المشروع. يمكنك تحسين ملف `README.md`، أو إضافة أدلة جديدة، أو تحسين الملفات الحالية.
- افتح طلب سحب مع تغييرات التوثيق الخاصة بك.
